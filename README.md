# VendorPulse — Marketing Website

The marketing website for [VendorPulse](https://vendorpulse.in) — the operations platform built specifically for automotive treatment vendors in India.

## Pages

- `index.html` — Home
- `product.html` — Feature walkthrough
- `why.html` — Positioning and comparison vs. WhatsApp+Excel, generic CRMs, DMS systems
- `pricing.html` — Pricing (contact-us model)
- `about.html` — Mission and founder story
- `contact.html` — Demo request form (Formspree-powered)

## Tech

Static HTML, CSS, and a small amount of JavaScript. No build step. Deployable to any static host.

## Deployment

Auto-deploys to Cloudflare Pages on every push to `main`.
